# 可视化聊天：界面设计稿说明

> 评审稿 v0.1，配套 [交互设计稿](chat-visual-mode-prototype.html) 与 [完整方案](chat-visual-mode-design.md)。示例提交和会话均为演示数据。

## 页面结构

沿用截图中的浅灰背景、白色聊天卡片、蓝色主按钮和底部输入框。聊天主列建议宽 820–960px。左侧继续使用现有导航，本稿用简化项目栏表示，不改全局导航规格。

```text
项目聊天 / AiAgent                                  当前项目
  用户：请解释这个版本的聊天链路
  助手：来源摘要 / 架构图 · v1
        ┌──────────────────────────────┐
        │   浏览器 → 聊天 API → Agent   │
        │                        ↓     │
        │                     工具服务 │
        └──────────────────────────────┘
        图形说明       [展开] [继续编辑] [版本] [下载]

  [Git: 示例提交 ×] [引用消息: 2 条 ×]
  ┌────────────────────────────────────┐
  │ 描述你想看清楚的结构、流程或变化…    │
  │ [文字|可视化] [选择来源] [架构图 ▾] │
  │ 原有 AGENT / 模型 / 推理控件    [↑] │
  └────────────────────────────────────┘
```

## 组件与交互

| 组件 | 规格和行为 |
| --- | --- |
| 模式切换 | 输入框底部左侧；文字/可视化二选一。切回文字保留未发送的可视化配置，但不带入普通请求 |
| 来源按钮 | 在可视化模式显示。打开面板，提供 Git 历史、对话消息、已有图形三类；纯文字方案可不选来源 |
| Git 列表 | 仓库、分支、搜索、提交说明、作者、时间、短 SHA；选中后明确显示完整版本信息。对比模式额外展示 A/B 槽位 |
| 对话列表 | 默认当前项目；先选会话再选消息，选中数量常驻底部；不以整会话勾选替代消息授权 |
| 图形类型 | P1 展示自动、架构、流程、时序；后续类型按能力开放。不要展示无法工作的按钮 |
| 来源标签 | 输入框上方；清晰区分 Git / 消息 / 图形版本；每个可删除，点击可重新选择 |
| 图形卡片 | 白底、细边框、14px 圆角；标题、来源、状态、图、结论和操作分区 |
| 节点详情 | 点击节点后在图旁显示介绍、来源类型和证据；“追问”回填输入框，不自动发送 |
| 展开查看 | 当前页大画布覆盖层；关闭回到原消息滚动位置；Esc 关闭，焦点回到触发按钮 |
| 新版本 | 新助手消息引用新 revision，旧消息固定；正在更新时展示上一有效图和更新状态 |

## 状态文案

| 状态 | 建议文案 / 操作 |
| --- | --- |
| 空白 | “选择一条 Git 记录，或描述你想看清楚的流程。” |
| 无仓库 | “当前项目还没有可读取的代码库，可改用对话内容生成。” |
| 未选来源 | “将根据你的文字生成方案示意图。” |
| 进行中 | “正在读取选中的提交…”“正在分析结构…”“正在校验图形…”；提供停止 |
| 有效 | “已生成 · v1”；代码依据与方案示意使用不同标签 |
| 部分依据 | “部分关系为推断，点击节点查看依据。” |
| 历史缺失 | “本地没有这个提交的完整内容，请补全历史后重试。” |
| 权限变化 | “来源已不可访问，暂时无法查看此图。” |
| 校验失败 | “这一版未通过图形校验，上一版已保留。”；重试/调整范围 |
| 已取消 | “已停止生成”；不能同时显示重试倒计时 |

## 视觉与响应式

- 背景 #F6F8FC，主色 #2862F5，正文 #1E293B，次级文字 #64748B，边框 #DEE5EF。
- Git 证据蓝色、对话方案紫色、推断琥珀色；同时提供文字标签，不能只靠颜色。
- 画布使用浅点阵背景、细连线、低饱和模块卡片；第一视图突出主链路，细节放节点面板。
- 低于 768px 隐藏示意项目栏，工具栏换行，来源面板全宽，节点详情改底部区域。
- 画布默认不拦截页面滚轮；需要缩放时显式操作。支持 reduced-motion、可见焦点与文字版结构说明。

## 如何评审 HTML

直接用浏览器打开 HTML，无构建、无网络依赖。可切换文字/可视化、选择 Git 或对话来源、切换三种图、发送演示问题、点选节点、回填追问、打开大画布。

该文件刻意使用固定示例，不读取真实仓库或会话。版本历史、双版本对比、下载及权限拦截以设计文档为准，尚未实现于演示稿。重点确认入口位置、选源方式、图形在消息中的阅读体验，以及是否需要优先做两版本对比。
