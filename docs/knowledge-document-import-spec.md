# 知识库文档导入规格

## 目标

把知识库“添加文档”升级为可靠的批量导入入口。用户可以多选或拖放文件；系统保留受支持的原始文档，逐项报告结果，并在存在成功导入项时自动重建当前知识库索引。

## 已确认范围

- 直接支持 Markdown、TXT、CSV、JSON/JSONL、XML、YAML、HTML、PDF、DOCX、XLSX、PPTX。
- ZIP 只展开其中受支持的文档，不保留压缩包目录层级；拒绝路径穿越、嵌套 ZIP、损坏或加密压缩包及超限内容。
- 旧版 `.doc/.xls/.ppt` 不做不可靠解析，明确提示另存为 DOCX/XLSX/PPTX。
- 单批最多 50 个上传文件或可导入条目；上传单文件不超过 25 MB；ZIP 解压后单文件不超过 25 MB、合计不超过 100 MB。
- 批次采用部分成功语义，每项返回 `imported`、`skipped` 或 `failed`；单项失败不回滚其他成功项。
- 同一知识库内内容哈希相同的文档跳过，避免重复索引；文件名相同但内容不同的文档允许作为新文档保存。
- 只要本批存在成功项，就以知识库全部有效文档异步重建索引；没有成功项时不创建空索引任务。

## 接口契约

`POST /api/v1/knowledge/{kbName}/upload` 接收 multipart `Files`，返回知识库摘要、逐项结果、可选索引任务 ID 和批次消息。逐项结果包含原始文件名、状态、消息及成功项的文档 ID。创建知识库时的初始文档使用相同的服务端校验与导入策略。

## 验收

1. 点击多选和拖放均可提交支持格式及 ZIP。
2. ZIP 内安全且受支持的条目被导入；不支持或嵌套条目逐项显示为跳过。
3. 路径穿越、损坏/加密 ZIP、空文件和超限内容不会写入知识库原始文件目录。
4. 重复内容被跳过，其他合法文档仍成功导入。
5. 页面展示每项结果；成功批次返回任务 ID 并自动进入索引流程。
