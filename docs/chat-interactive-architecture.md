# 聊天交互架构图

## 五种图形与画布优化（2026-10-07）

选择器现在仅显示架构、工作流、时序图、数据流、生命周期，默认架构。五种类型都支持代码范围和 Git 摘要；历史 Mermaid 消息继续渲染。

| 类型 | 布局与语义 |
| --- | --- |
| 架构 | 职责分组边界分行排列，避免每组一列导致无限加宽 |
| 工作流 | 按依赖分层，判断菱形、起止节点和条件标签 |
| 时序图 | 参与者横排、生命线、按数组顺序编号的消息；支持返回、重复及自调用 |
| 数据流 | 按依赖横向分层，存储节点与数据标签 |
| 生命周期 | 状态分两行往返排列，圆角状态与事件转换，保留循环 |

画布默认浅色，增加细网格、图例、节点文字换行、折线候选避让与共享线段惩罚。初次打开、展开和窗口尺寸变化自动适配；手动缩放或拖动后可点「适配窗口」恢复。复杂稠密图仍可能交叉，支持拖动与拆图，不保证最优布线。

JSON version 1 增加可选 `diagramType`（architecture/workflow/sequence/dataflow/lifecycle）、节点 `kind`（component/decision/store/start/end）、边 `style`（solid/dashed）；缺失类型的旧图按架构渲染。保留原有数量、长度、引用与纯文本校验。

增加 HTML 导出，包含标题、图例、完整 SVG、可折叠的节点说明与来源、关系明细。支持原始尺寸阅读开关，使用原生 details 与 CSS，无脚本、禁止联网，不依赖外部资源。HTML/SVG/PNG 保留当前布局和主题，但恢复全部节点及边的可见度；JSON 保持原始语义与消息顺序。路径探索仍在会话内进行。

验证覆盖五类协议、循环和孤立节点、跨节点连线避让、自动适配、实际 Markdown 渲染、五类选择器、主题/搜索/拖动/路径、四种导出、移动端和无效流式数据。浏览器使用临时页面和模拟目录接口，不调用真实模型。

## 原始交互能力

在聊天点击「可视化」，默认选中「架构」。弹窗不显示固定示例入口。可直接使用当前对话和已选项目资料，也可在弹窗选择代码库，逐级浏览根目录，选择目录或 `.sln/.slnx`、工程、JSON 文件。确认配置后，在聊天输入分析要求并发送；仅选择代码范围也可直接发送默认分析请求。多个解决方案时，提示词明确限定选定入口与必要依赖，不允许静默换用其他入口。

回复中的 `aiagent-architecture` JSON 自动成为交互图。支持节点详情、模型标注来源、直接关系列表、上游/下游高亮、有向最短路径追踪、深浅画布、分组配色、节点搜索、拖动节点调整位置、拖动画布平移、重置布局、缩放、滚动浏览、大图及 JSON/SVG/PNG 导出。节点可通过 Tab 聚焦、Enter/空格选择，大图支持 Escape 关闭。继续对话要求修改图时，模型返回完整新图；历史版本保留在各自的聊天消息中，重新打开会话即可再次渲染。画布当前选择、主题、拖动位置和缩放不持久化；图片导出保留当前布局与主题，JSON 导出保留语义数据。

## 实现选择

正式聊天图采用独立 React/SVG 画布，不动态调用 Archify CLI，不增加后端渲染进程。原来的 Archify 固定示例、许可证和隔离策略保留。正式图提供主题切换、节点拖动、搜索与按图形类型的布局，复杂大图宜拆分；不声称复刻 Archify 全套布线能力。

生成使用既有模型与普通聊天提交链路，不修改 ChatStreamProvider、后端 API 或数据库。选择的范围和输出格式要求随用户消息保存；重试沿用请求快照。不同项目/会话会清空范围，异步目录响应在卸载/切换目录后失效。取消弹窗不提交草稿选择。

## 数据契约与边界

```json
{
  "version": 1,
  "title": "系统架构",
  "nodes": [
    {"id": "web", "label": "前端", "group": "应用层", "description": "负责交互", "source": "对话方案，尚未核实代码"},
    {"id": "api", "label": "接口", "group": "服务层", "description": "处理请求", "source": "对话方案，尚未核实代码"}
  ],
  "edges": [{"from": "web", "to": "api", "label": "请求"}]
}
```

校验在 `front/lib/chat-architecture.ts`：最多 100000 字符，1–40 个节点、100 条边，限定字段长度，拒绝重复/非法 ID 和不存在的节点引用。仅投影允许字段，文本通过 React 和 SVG 文本节点转义，不接受模型提供的坐标、脚本或 HTML。无效/尚未完整的流式 JSON 显示提示和受限源数据，允许用户继续对话修正。导出仅从当前受控 SVG 或已校验 JSON 产生 Blob；PNG 最大边不超过 4096 像素。无外部字体、图片或网络依赖。

图形权限继承聊天消息权限，不另建公开产物链接、不写入 public 或 localStorage。`source` 是模型标注的文本，UI 明示其性质，不跳转任意来源 URL，不宣称系统已核实。选定路径只是分析范围提示，读取仍使用原来的服务端授权；不具备代码读取能力的模型应说明无法读取，不能假造证据。仅分析提示不替代 Agent 工具本身的权限设置。
