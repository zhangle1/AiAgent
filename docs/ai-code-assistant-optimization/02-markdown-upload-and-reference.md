# 任务 02：Markdown 上传与聊天引用

## 目标

允许用户将业务资料、接口说明和日志摘要以 Markdown 上传或引用到聊天中，供模型辅助分析。

## 范围

- 仅支持 `.md`、`.markdown`、UTF-8 文本；
- 文件归属项目和上传用户，读取时重新进行项目权限校验；
- 设置文件大小、字符数、单次引用数和总上下文上限；
- 后端读取、截断并以“不可信参考资料”边界注入 Prompt；
- 支持项目内已注册仓库 Markdown 的搜索、预览与引用。

## 非范围

- 首期不支持 PDF、Word、Excel、PPT 自动解析；
- 浏览器不得直接提交模型 Prompt 或任意本地路径。

## 验收与测试

1. 有权限用户可上传并引用 Markdown；无权限用户不能列出或读取。
2. 上传超出限制、非 Markdown、路径遍历或符号链接越界均被拒绝。
3. 模型能依据已引用文档回答，但文档中的指令不能改变系统规则或获得工具权限。
4. 会话仅记录引用元数据，不持久化无必要的完整文档正文。
