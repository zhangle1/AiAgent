# 任务 06：试点与效率度量

## 目标

以真实项目任务验证 AI 工具是否将高频研发和排障的端到端人力时间提升至少 50%。

## 试点计划

1. 张乐汇总问题，并与张自强、姜帆确认 P0/P1 优先级。
2. P0 能力可测试后，邀请福邦、闲客项目组加入试点。
3. 最晚下周末召开复盘会议，决定扩大、整改或收缩能力。
4. 朱锵贤组织实施人员使用复盘，沉淀高频场景与标准流程。

## 指标

| 指标 | 记录方式 |
| --- | --- |
| 效率提升 | `(人工基线耗时 - AI 辅助耗时) / 人工基线耗时` |
| 首次可用定位时间 | 从提问到得到可验证文件/模块范围 |
| 无关检索率 | 无关项目/端/模块命中 ÷ 总命中 |
| AI 变更接受率 | 人工确认合入的变更 ÷ AI 建议变更 |
| OCR 可用率 | 成功取得可用文本的 OCR 请求 ÷ OCR 请求 |
| 安全事故 | 越权读取、提交、推送、密钥泄露，目标为 0 |

## 验收与测试

1. 每个试点任务都有人工基线、AI 耗时、结果质量和返工记录。
2. 指标按项目、场景、模型和是否使用 OCR/索引拆分，避免平均值掩盖问题。
3. 不以取消人工审核或降低安全控制换取效率指标。
4. 复盘输出继续推广、修复项、停止项与负责人。
