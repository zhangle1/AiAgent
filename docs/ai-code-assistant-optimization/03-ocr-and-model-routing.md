# 任务 03：OCR 与模型路由

## 目标

让非视觉模型在用户上传报错截图时，可选择使用本地 OCR 文本进行分析；未配置能力时给出明确提示而非卡住。

## 范围

- 原生视觉模型使用受控原图；
- 第三方模型可启用 PaddleOCR 作为文本降级；
- OCR 结果带图片 ID、引擎、语言、置信度、耗时与截断标记；
- OCR 文本以不可信附件边界加入 Prompt；
- 管理员可查看健康状态并开关 OCR。

## 部署约束

- 轻量部署包默认不携带 Python/OCR；
- 需要识图的环境显式使用 `-IncludePythonWorkers` 打包并完成 Python Worker 配置；
- OCR 失败或超时不阻断纯文本聊天。

## 验收与测试

1. 非视觉模型 + 已配置 OCR：能从中英文报错截图取得文本并给出分析。
2. 非视觉模型 + 未配置 OCR：界面明确提示无法识图，文字聊天仍可用。
3. OCR 超时、依赖缺失、图片过大时均有可读错误和审计记录。
4. 模型 Prompt 中 OCR 内容具有不可信数据边界。
