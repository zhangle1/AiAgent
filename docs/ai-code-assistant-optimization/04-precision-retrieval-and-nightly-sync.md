# 任务 04：精准检索与夜间同步

## 目标

降低复杂项目的首次响应时间与无关代码命中率，并在夜间联网窗口更新本地代码与索引。

## 范围

- 聊天检索支持项目、仓库、端类型、业务模块、接口/类/日志关键字等限定；
- 对“调拨”等跨端同名词，未指定端时先给出候选范围供确认；
- AI 回答中说明实际检索范围和命中依据；
- 夜间任务依次拉取授权仓库、记录提交号、更新 Agent Markdown、更新索引和任务日志；
- 同步失败保留上一次可用索引。

## 非范围

- 不要求日间实时联网拉取；
- 不因全局相似关键词而自动读取无关项目。

## 验收与测试

1. 指定“Web 端调拨”不会命中 PDA 或其他项目同名代码。
2. 模糊提问会展示候选模块或要求补充端类型，而非直接给出错误结论。
3. 夜间任务成功后记录版本；失败后旧索引仍可服务聊天。
4. 断网日间仍可查询最后一次同步的受控副本。
