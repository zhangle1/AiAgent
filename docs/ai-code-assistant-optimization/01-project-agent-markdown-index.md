# 任务 01：项目 Agent Markdown 索引

## 目标

为每个接入项目生成受控的项目结构 Markdown，让 AI 在代码问答前先理解入口、模块和业务关键词，避免默认全盘扫描。

## 范围

- 生成 `AGENT.md` 或 `docs/ai-project-map.md`；
- 内容包含技术栈、受控目录树、入口文件、模块、业务关键词映射、代码版本与生成时间；
- 跳过 `.git`、依赖目录、构建产物、缓存、密钥与符号链接越界路径；
- 聊天编排在代码类问题时优先读取该文档。

## 非范围

- 不读取未注册目录；
- 不生成或暴露真实密钥、连接串、绝对路径；
- 不替代后续按需代码搜索。

## 验收与测试

1. 为一个复杂项目生成索引后，可在文档中看到模块、端类型和入口文件。
2. 询问“PDA 调拨流程”时，AI 先说明其检索的模块/目录，而非扫描其他端的同名功能。
3. 索引不存在或过期时，AI 提示刷新，不伪造目录结构。
4. 文档内不包含密钥、绝对路径、`node_modules` 或 `.git` 内容。
