## 实际运行结果

隔离环境采用临时 SQLite、随机回环端口、合成账号和可控上游，未使用真实业务数据、密码或供应商密钥。实际 Furion 动态控制器、构建后的 Electron 和 Rust host 参与验证；平台界面加载实际 KnowledgeWorkspace 组件及生产 CSS，通过真实 HTTP 连接临时后端。

1. 从桌面“坤伴订阅”弹窗登录，发送两轮聊天。两轮均经实际 Agent 和持久化链路，原文自动上传，后续内容追加到同一 URI、同一文档 ID，用户原始输入没有重复。计数为文档 1、任务 0、解析记录 0、产物 0；模型端点调用正好 2 次，对应两轮显式聊天，同步没有额外模型调用。
2. 用真实 Rust host 预置已有订阅会话，再启动 Electron。无需发送新聊天，启动扫描补传已有用户／助手原文；新增模型调用为 0。
3. 管理员能列出、读取和预览其他人员的会话；普通账号既看不到其目录，也不能用猜测 URI 下载。网页登录 Cookie 不能调用客户端上传接口，账号断言与客户端令牌不一致返回 403。
4. 用普通账号和管理员分别请求旧知识库的文件、内容、上下文树、重新索引、来源搜索、编译及删除接口，共 14 个请求全部返回 404。管理员读取他人会话必须经过有范围校验的资源接口。
5. 实际平台界面展示“会话”目录、原文说明和 Markdown 预览；切换普通账号后没有他人的工作区。截图已人工目视检查。首次截图因隔离 Electron GPU 捕获超时失败，仅为浏览器测试启动器关闭硬件加速后重跑，所有界面断言和截图通过，产品代码未因此修改。
