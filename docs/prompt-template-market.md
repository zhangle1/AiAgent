# Prompt 模板市场（一期实现）

## 用户入口与范围

- 前端路由：`/prompt-templates`，左侧“工作台”中紧跟“聊天”。
- 提供研发阶段筛选、全文检索、全部/已收藏/我创建的分区、创建、点赞、收藏、MD 导入与导出。
- 模板详情采用左侧预览/编辑、右侧配置的三栏弹窗；正文变量统一为 `${field}`。
- 一键使用先在服务端校验变量与项目权限并渲染正文，再通过浏览器 `sessionStorage` 一次性交给 `/chat` 的输入框；聊天实际发送时沿用既有会话与流式协议。

## 后端契约

路由前缀：`/api/v1/prompt-templates`。

| 接口 | 职责 |
| --- | --- |
| `GET /list` | 返回当前用户可访问的模板及其点赞、收藏状态。 |
| `POST /`、`PUT /{id}`、`DELETE /{id}` | 创建、保存和软删除用户模板。 |
| `POST /{id}/like`、`POST /{id}/favorite` | 幂等更新当前用户状态。 |
| `POST /{id}/use` | 校验变量、项目访问权限，渲染正文并累计使用次数。 |

模板数据写入 `ai_prompt_template`，用户状态写入 `ai_prompt_template_user_state`。启动时 CodeFirst 创建表并补齐索引；首次访问会写入 6 个官方研发交付种子模板。

## 权限与安全

- 个人模板只对创建者可见；项目模板需要项目访问权限；团队模板对已登录用户可见。
- 创建/编辑中若绑定项目，后端通过 `IProjectAccessService` 再次校验；更新和删除仅创建者或管理员可执行。
- 变量名白名单为 `^[A-Za-z_][A-Za-z0-9_]*$`；正文变量必须在属性定义中存在；变量值、正文和 MD 文件均有长度限制。
- 前端 MD 导入仅解析元数据和 Markdown 正文，不执行脚本或外部资源；导出不含会话内容、密钥或项目路径。
