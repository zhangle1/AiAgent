### 3. 补齐文件摘要与目录 L0/L1 语义生成

对应提交：`13d66a7 feat: 完善知识库 L0/L1 语义生成与预览`

- 目录资源任务先保存解析正文（L2），再由设置中的 Codex 或 LLM API 生成文件摘要，并从所属目录向上汇总目录概览（L1）。
- 从 L1 简介段落提取简短摘要（L0），避免额外一次独立模型调用。文本正文解析不调用 LLM，图片解析继续使用现有 VLM 能力。
- 语义存储使用不可变版本目录，通过原子替换 manifest 一次发布同版本的 `.overview.md` 与 `.abstract.md`，避免取消或失败留下半对可见结果。
- 使用原文、解析正文哈希及后代资源指纹判断缓存有效性；来源变化时拒绝发布或显示旧缓存为最新，重复解析相同内容可复用结果。
- 目录预览支持 L0/L1 切换与 Markdown 下载；文件页补齐知识摘要展示、任务恢复轮询、完成后的内容刷新和异步响应隔离。
- 语义预览禁用图片和外链，不执行模型 HTML；个人资料语义仅汇总至本人根目录。
- 新增语义生成、缓存、取消、预算、原子发布、失败后正文读取等后端测试，以及使用模拟 API 的浏览器测试。

工作价值：将原先只有解析正文的资源升级为可预览的分层语义内容，并通过缓存和原子发布提高一致性。

### 4. 分离队列调度与知识执行，完善任务诊断

- 任务中心查询时尝试补写终态；数据库仍不可写时，用内存终态覆盖返回的状态和错误，减少完成结果与界面状态不一致。
- 状态筛选不再改变摘要统计，统计范围仍为最近指定数量的任务；取消和重试按任务 ID 回读，不依赖列表窗口。
- 已完成任务增加“重新处理”入口，活动任务重复提交沿用去重逻辑；历史任务缺少阶段时明确提示无法确认 L0/L1 是否生成。
- 增补语义失败阶段、错误展示、重试成功、缺少语义服务和终态写库异常相关测试。

工作价值：用户能够区分“正文解析成功”和“语义生成完成”，并从任务中心定位失败环节与发起重试。
