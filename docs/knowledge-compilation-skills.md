# 知识编译目标与技能（2026-10-13）

## 使用流程

右侧入口显示“浏览目录 /ls、读取正文 /read、搜索资料 /search、处理状态 /status、编译资料 /compiler”，英文命令协议保持不变。目录命令的目标资源可手动输入，也可打开当前授权范围内的树状选择器并按名称、路径过滤。

添加资源弹窗的目标目录同样提供树状浏览，上传与新建目录均使用所选父目录，不依赖当前正在预览的文件位置。

编译弹窗显示原始资源树，默认勾选当前目录的文件，支持跨可见目录选择和过滤。最多选 32 个文件，过滤不清除已选内容，生成产物不能成为编译来源。

产物默认保存到本人摘要工作区，也可选择已有资料、项目或本人原始目录。显式选择后，文件摘要及目录 `.overview.md`、`.abstract.md` 保存到该父目录的 `_compiled/`，树中显示为“编译产物”。文件 URI 带来源文档 ID，避免同名原文件覆盖；原始文件和 L2 不移动或改写。原文件的知识摘要页提供可见产物链接。

资料 / 项目沿用既有公共资源可见范围，并不新增项目授权体系；个人来源禁止发布到公共目录。其他用户目录和生成产物目录不能成为目标。后台队列再次校验个人来源与目标归属。

## 技能

内置 `llm-wiki` 来自 `backed/Services/Knowledge/Skills/llm-wiki/SKILL.md`，以显式资源名嵌入后端程序集。它生成文件知识摘要、目录 L1 概览及 L0 简介，保留主要语言、实体、业务规则、约束、来源和不确定性。

“生成 / 编辑技能”打开独立对话弹窗：选择已配置 API 模型，描述需求、继续调整，然后检查或手动编辑名称、说明与指令。生成不会自动保存；点击“保存并用于编译”后，新技能立即出现在选择框。内置技能另存为本人自定义技能。

技能是提示文本，不执行脚本、安装插件或扩大工具权限。自定义技能使用本人 `knowledge_skill:<owner-hash>` 设置快照持久化，保存完整 `SKILL.md` 文本；同一 ID 的最新版本用于新任务。每人最多 32 个自定义技能，其他用户不能读取、修改或选用。

任务入队前按服务器身份解析技能 ID，客户端指令不能覆盖已保存技能。`ConfigurationJson` 保存 `target_uri/skill_id/skill_name/skill_instructions` 和本批模型、预算；入队后编辑技能不影响已有任务，任务中心重试沿用原快照。自动上传 / 重新解析的默认流程不继承全局设置中的这些批次字段。

技能正文计入上下文预算。语义指纹包含来源正文与技能内容；目录指纹还包含已发布子文件摘要，后续文件完成会使旧目录概览失效并重新生成。一个任务不使用自己的技能替其他待处理文件生成摘要。

## 自动预算修复

2026-10-13：修复“模型输出超过预算”的中文误判。UTF-8 字节数不能用作真实输出 token 数，已移除该拒绝条件。语义生成也不再以固定 12000 字符拒绝正常 Markdown 输出；供应商返回 `finish_reason=length` 时仍按真实截断报错。

L0/L1 按所选模型配置窗口预留输出和协议空间，取消 32000 输入封顶、16000 固定分段和 256000 正文字符限制。分段与归并计算 JSON 转义大小，保留全部 Unicode 原文，超出窗口自动分批；压缩不收敛明确失败。输出请求使用供应商默认策略，未额外发送固定 `max_tokens`。

新编译弹窗默认调用次数上限为 0（不限），即使旧全局设置保存为 48；可以手动填写正整数，设置页也支持 0，移除原 96 次上限。新默认配置为 0；已有显式设置和历史任务快照不自动覆盖。任务超时仍可配置，取消和服务停止继续有效，已有失败任务可重试。

## API

- `GET /api/v1/knowledge-agent/options`：认证后返回安全模型目录、默认配置和本人技能列表。
- `POST /api/v1/knowledge-agent/skills/draft`：模型、需求、对话历史和可选草稿 → 回复与可编辑草稿；有调用超时、输入及上下文限制。
- `POST /api/v1/knowledge-agent/skills`：校验并保存本人技能，返回技能与完整 Markdown。
- `POST /api/v1/knowledge-agent/compile`：来源 URI 列表及本批配置 → 已入队任务与失败原因；任务阶段和错误继续由任务中心提供。

本轮不新增数据库列：目标和技能使用既有可空配置 JSON，技能使用既有设置快照表。需要更新并重启后端加载新服务和内置资源，刷新前端；历史失败任务保持失败，可重新提交或在任务中心重试。
