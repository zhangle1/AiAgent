# 资料文件删除

## 使用与行为

选中原始文件，在预览顶部点击「删除文件」，核对文件名后确认。删除后刷新目录并回到父目录，原文件及依赖它的解析章节、图片和编译投影隐藏。磁盘原文件、解析版本、聊天和任务历史保留；此操作不回收磁盘空间，也不重建或清空旧 RAG 活动索引。

原来的目录栏清理图标打开「清理失效记录」，只列入原文件缺失、路径失效等记录。能够正常预览的 PDF 不会列入，扫描结果为零并不表示文件不能删除。空列表现在提示使用文件顶部的删除按钮。

普通用户只能移除本人的原始资料；共享资料、项目资料由管理员管理，项目访问权另行复核。管理员对他人会话仍只读。目录、解析章节、图片和编译产物不提供单独删除入口，应操作对应来源文件。存在排队、执行、取消中任务或文档正在解析／索引时阻止删除，先取消任务并等待结束。

删除确认默认聚焦「取消」，支持 Escape 关闭和焦点恢复。提交期间禁止重复提交或关闭；失败保留提示和文件选择，允许重试。资料状态和权限以服务端再次检查为准。

## HTTP 与实现

`DELETE /api/v1/knowledge-resources/file?uri=<编码后的逻辑 URI>&document_id=<来源 ID>`

成功返回 `{deleted:true, document_id, uri}`。未登录返回 401，越权返回 403，不存在或已删除返回 404，非法目录／生成文件输入返回 400，选择不匹配或存在活动任务返回 409，请求断开返回 499。GET 同路径的原有预览与下载保持。

资源节点增加 `can_delete`，只用于界面展示。服务重新校验登录身份、规范化 URI、原始文档 ID 与 URI 对应关系、项目可见性和活动任务。使用独立数据库客户端与事务，按来源 URI、路径、哈希、状态和更新时间作条件软删除，保存删除时间；提交前取消会回滚。服务不打开或删除物理文件。

来源行删除后，现有目录投影和文件读取的来源可见性校验阻止继续访问相应生成节点。前端也立即过滤同一 document_id 的节点，取消旧读取结果，再刷新服务端目录。成功响应必须与确认的 URI／ID 匹配。
