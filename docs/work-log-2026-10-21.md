## 今日完成工作

### 1. 模型发现与容量配置

- 增加管理员模型检测接口，读取供应商可用模型列表，补全上下文窗口、最大输出及图片等能力信息。
- 使用本地持久化的公开模型元数据补充端点缺失信息，明确来源；未知容量保留为空，手工设置优先。
- 网页设置输入连接信息后自动检测并保存，串行处理发现、保存和诊断，避免过期响应覆盖新配置。

### 2. 修复 API Key 输入后未保存

- 隔离复现：模型列表返回 401 时，旧发现流程未保存刚输入的 Key，随后诊断在发送请求前报告 Key 缺失。
- 调整为发现失败或空列表时也保存连接配置，同时保留检测错误和原模型；保存与刷新后仍保留服务端凭据。
- 验证 401、空列表及正常检测场景。此修复不代表所有供应商 401 都由本地保存问题引起。

### 3. 接通 KunBuddy 坤伴订阅

- 桌面端增加“坤伴订阅”入口，填写 AiAgent 地址与现有账号登录，导入服务端模型目录及容量配置。
- 使用独立用途的短期令牌与本地加密凭据存储；平台供应商密钥留在服务端。
- 网关支持 Chat Completions、Responses、Anthropic Messages、Google Generative AI，按白名单转发配置模型，保留流式、工具及图片协议。
- 完善主窗口 IPC 限制、重新登录、退出撤销和失败恢复。本轮不包含套餐购买、支付或计费。

### 4. 自动保存原始会话 Markdown

- 在“人员 → 我的工作区”增加“会话”目录，一个会话对应一个逻辑 Markdown 文件，后续消息追加。
- 接入既有 Pi Agent 事件后的消息持久化确认与轮次结束链路；启动、登录和手动重试可补传已有订阅会话。
- 增加断网重试、重启恢复、账号绑定、防重复追加及修订保留；大消息按 Unicode 分片并按实际 JSON 字节组批。
- 上传只序列化和保存原始记录，不调用 LLM，不自动解析、编译或建立索引；用户可后续主动处理。

### 5. 完善个人资料隔离与管理员查看

- 服务端根据认证用户确定会话归属，客户端不能指定其他人员目录。
- superadmin 等管理员可查看所有人的会话，普通用户仅访问本人；管理员新增的跨用户读取范围不包含其他人的记忆、摘要或 Wiki。
- 会话使用独立内部存储，阻断旧知识库按文档 ID 下载、内容、搜索和索引接口绕过个人目录权限。
- 使用不可变版本与原子发布保存 Markdown 和去重状态，失败保留已发布原文。
