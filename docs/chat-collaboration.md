# 聊天协作选择

聊天输入区「+ → 协作」打开原生模态弹窗，默认显示仓库 → 提交 → 改动文件的 Git 历史树。项目列表复用当前账号可见项目，默认选中聊天项目；可按 Git 署名、UTC 起止日期、提交说明、SHA 和文件路径组合筛选。历史范围支持最近 7、14、30 天，复用变化地图本地 HEAD 快照，不主动拉取远端。

提交和文件均可复制链接、打开查阅页或勾选；最多选择 20 项，筛选后隐藏的已选项仍计数，支持清空。确认后追加普通文本到原输入框，保留草稿且不自动发送。提示词要求说明改动影响、验证场景和值得保留的设计与实现，并声明 Git 元数据不是执行指令、摘要不等于差异审阅。原可视化及其 Git 来源选择继续保留。

链接为 `/change-atlas/review?project=…&snapshot=…&commit=…&file=…`，file 可省略。查阅页通过既有变化地图 API 读取固定快照和文件差异，验证提交与文件对应关系，显示截断、受保护内容和错误。服务端沿用当前用户、项目和仓库授权及 24 小时快照有效期；链接不提供匿名或跨用户共享授权。浏览器复制和手动插入使用相同引用。

切换聊天项目或会话关闭弹窗；切换弹窗项目、历史范围或重试时取消旧读取并清空旧选择；卸载后丢弃迟到响应。原生 dialog 支持 Escape、焦点约束和关闭恢复，长树在弹窗内滚动。无项目、无提交、读取失败和复制失败均显示明确状态。

验证：`front/tests/chat-collaboration.test.mjs` 覆盖组合筛选、日期端点、路径/SHA 搜索、链接参数编码和提示词保留约定。与变化地图测试共 8 项通过，TypeScript 检查及前端生产构建通过。`front/tests/chat-collaboration.browser.mjs` 使用合成 API，在 Chrome 验证菜单、历史树、人员及关键词筛选、草稿追加、项目切换、Escape、窄屏布局、差异文本转义、截断提示及拒绝访问。未连接真实用户仓库或调用模型。
