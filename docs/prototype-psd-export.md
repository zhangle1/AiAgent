# 原型设计产物与 PSD 导出

每个原型在左侧显示为可展开的目录，包含 HTML 与桌面（1440px）、平板（768px）、移动端（390px）PSD 入口。HTML 沿用现有服务端保存机制；PSD 点击时在浏览器生成并下载，同一页面会话内缓存，HTML 变化后自动失效。PSD 不上传服务器，刷新后重新生成。

导出使用禁用脚本的隔离 iframe、html2canvas 和 ag-psd。页面背景是独立图层，页面区域对应图层组，包含可移动、隐藏的像素图层。区域名称优先取 `data-psd-name`、`aria-label`、元素 ID。建议生成 HTML 使用内联 CSS、语义化区域及 `data-psd-name`，避免全部内容堆在单一区域。

文字、矢量、组件效果当前栅格化，不提供原生文字层或智能对象；附带默认隐藏的完整预览参考层。外部样式表与脚本不执行，跨域图片需服务端允许 CORS，复杂 CSS 或脚本生成的内容可能与交互预览不同。像素图层按 DOM 区域排序，复杂跨区域叠放需要设计师调整图层顺序。

限制：高度最多 12000px、画布最多 1600 万像素、区域最多 40 个、保留图层最多 4800 万像素；超限明确失败，可拆分页面后重新导出。多个目录导出串行执行，失败后可重试。没有更改公开分享与权限接口。

验收：展开目录，下载 HTML 和三种 PSD；HTML 修改后重新导出；确认 PSD 分组、图层位置和透明区域；确认导出 HTML 内脚本不执行；确认超长页面报错后仍可再次导出。Photoshop 内视觉一致性需人工打开产物验收。
