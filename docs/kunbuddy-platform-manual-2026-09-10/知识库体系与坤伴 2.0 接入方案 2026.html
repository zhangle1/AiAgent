知识库体系与坤伴 2.0 接入方案

LlamaIndex、PageIndex、GraphRAG 与 LLM Wiki 的定位、协同与落地路径 · 2026-09-13

四类方案概念速览协同路由2.0 架构接入步骤知识模型风险原则资料来源

结论：四类方案不在同一层。LlamaIndex 是数据接入和检索编排框架；PageIndex 是复杂长文档的树状推理检索；GraphRAG 用于实体关系和跨文档全局推理；LLM Wiki 用于长期、可读、可维护的知识沉淀。坤伴 2.0 应以统一事实与权限层为底座，由 Agent 路由层组合它们。

术语校正：PageIndex 的官方定位是无向量、基于推理的长文档 RAG，不是互联网搜索。互联网搜索应作为独立外部工具层，按时效性和可信度策略调用。

1. 四类方案分别解决什么问题

图 1 · 职责边界与协同关系

方案核心机制适合的问题不应承担的职责
LlamaIndexDocument / Node / Index / Retriever，连接数据与混合检索。日常事实问答、数据连接、检索路由。单独解决复杂长文结构或全局图谱推理。
PageIndex构建上下文树，LLM 逐层推理定位，无向量且可解释。长 PDF、方案、规范、合同与审计报告。互联网搜索、跨大量异构资料关系分析。
GraphRAG实体、关系、主张、社区与社区摘要。影响范围、跨文档关系、整体归纳。实时小问题的低成本检索。
LLM Wiki将资料编译为互链、版本化、可维护的 Markdown Wiki。架构、决策、术语、经验和技能沉淀。替代原始证据、实时数据或权限校验。

2. 相关概念

RAG在生成前检索外部上下文，把问题与可靠资料一起交给模型。
Chunk / Node 与向量Chunk / Node 是可引用的最小片段；Embedding / Vector 用语义相似度快速召回“意思相近”的内容。
知识图谱与主张图谱用实体、关系和带来源的主张表达事实网络；适合追问谁、什么、何时、影响了谁。
上下文树与知识编译上下文树保留章节层次以理解长文；知识编译将原始资料提炼为稳定、可链接、可审核的 Wiki 页面。
Provenance来源追溯：答案、实体或结论必须能回到原始文件、页码、段落、提交或业务记录。

3. 如何协同使用

问题类型优先能力应返回
接口怎么调用？当前配置是什么？LlamaIndex 混合检索片段、文件位置、版本与简洁说明
长规范对交付有什么要求？PageIndex 上下文树章节、页级/行级引用、约束清单
字段改动影响哪些系统和历史缺陷？GraphRAG实体关系路径、影响范围、主张来源
为什么选这个方案？以后怎么做？LLM Wiki 优先已确认决策、适用边界和原始证据
外部平台或政策今日有什么变化？互联网搜索工具链接、发布时间、抓取时间；不直接写入长期知识

4. 坤伴 2.0 目标架构

图 2 · 从资料接入到知识沉淀

  • 统一事实对象：项目、代码、需求、工单、文件、Git 提交、对话、附件及其来源、版本、权限和有效期。
  • 索引服务：在同一事实对象上生成可重建的 Wiki、向量、长文树和图谱索引。
  • Agent 路由：按问题意图、敏感性、时效性、成本与置信度选择能力。
  • 证据与反馈：回答带引用；高价值结论经规则或人工确认后写入 Wiki / 长期记忆。

5. 分阶段接入步骤

P0 事实底座P1 普通 RAGP2 长文与 WikiP3 图谱试点P4 Agent 协同

阶段交付内容验收标准
P0统一元数据、项目隔离、版本、权限、同步队列和引用格式。每条结果可回到项目、文件、版本和段落。
P1LlamaIndex 或等效服务接入代码、Markdown、工单和常用文档。常见问答有来源，召回、时延和引用完整性可度量。
P2PageIndex 处理重点长文，建立 Markdown Wiki、日志和审核流。长文答案可定位章节；决策可复用且回链原文。
P3选择高价值域试点 GraphRAG，如模块-接口-需求-缺陷-Git 提交。能回答影响范围，且关系与主张可追溯。
P4检索器工具化，由 CPS、APS 或代码 Agent 按策略调用。委派、工具、审批和结果均可回放并可人工接管。

6. 首批建议知识模型

  • Source：原始资料、来源类型、项目、版本、权限、内容哈希。
  • WikiPage：标题、类型、摘要、标签、状态、编译时间、审核人、来源集合。
  • Entity / Relationship / Claim：标准名称、别名、关系、时间范围、置信度、证据与冲突标记。
  • Trace：会话、模型、工具、输入摘要、输出、耗时、成本、结果与审批。

7. 风险与原则

  • 先治理再放大：来源、版本、权限和删除策略先于知识规模。
  • 原始事实与 AI 派生内容必须分开；摘要、实体和关系可重建、可撤销。
  • GraphRAG 成本较高，应从业务域试点并衡量增益。
  • 扫描件和图表密集文档需要 OCR、版面解析与人工抽检。
  • 外网搜索是临时低可信上下文，验证后才可进入项目知识。
  • 先建立评测集，持续比较正确性、引用率、时延、成本和人工介入。
