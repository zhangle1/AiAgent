# 坤伴平台手册交付目录

本目录汇总坤伴平台的优化版操作手册、可交互 HTML 手册、原始手册截图，以及当前架构和产品迭代资料。

## 客户介绍版（2026-09-18）

面向客户介绍平台价值、协同研发流程与交付保障，依据 2026-09-18 本地代码基线核对，含 10 个章节。与下方操作手册分别维护。

- [Word 手册](对外介绍-2026-09-18/坤伴Agent协同研发平台介绍手册.docx)：可编辑、可转发，含可点击目录。
- [PDF 手册](对外介绍-2026-09-18/坤伴Agent协同研发平台介绍手册.pdf)：12 页固定排版，适合直接发给客户。
- [HTML 手册](对外介绍-2026-09-18/坤伴Agent协同研发平台介绍手册.html)：单文件离线阅读、目录跳转和移动端适配。
- [客户资料包](对外介绍-2026-09-18/坤伴Agent平台客户介绍资料包.zip)：仅包含 Word、PDF、HTML 和 Markdown 正文。
- [正文源稿](对外介绍-2026-09-18/坤伴Agent协同研发平台介绍手册.md)：统一维护入口。

[事实核对表](客户手册事实核对-2026-09-18.md)供内部维护使用，不包含在客户资料包中。生成与校验入口为 `build_customer_manual.py` 和 `check_customer_manual.py`；原操作手册及参考资料保持原样。本轮交付为可公开分发的文档，未发布公网地址。

## 交付物

- `坤伴平台操作手册 2026-09-10.docx`：适合下载、打印和线下交付的优化版 Word 手册。

## 维护建议

界面、模型名单、部署地址和用户权限会随环境变化。功能改动后，请同时更新操作手册对应章节、截图和关联架构资料；不要在手册、截图、HTML 或示例中写入真实令牌、密码、连接串或生产数据。
