# 项目资料库导入规格

## 目标

将原“项目 Markdown 文档”的单文件入口升级为项目资料库：用户可点击多选或把文件拖入当前目录，系统将可解析资料统一转换成 Markdown，以继续复用预览、引用、检索、权限与 Git 变更链路。

## 已确认范围

- 直接导入：Markdown、TXT、CSV、JSON/JSONL、XML、YAML、HTML、PDF、DOCX、XLSX、PPTX。
- ZIP：只展开受支持文档；不保留压缩包目录结构；拒绝路径穿越，跳过嵌套 ZIP 和未知类型。
- 限制：一次最多 50 个上传文件/可导入条目；上传单文件 25 MB；ZIP 解压后单文件 25 MB、合计 100 MB；标准化 Markdown 仍遵守 2 MB/200,000 字符限制。
- Office 旧格式 `.doc/.xls/.ppt` 提示用户另存为 OOXML 新格式。
- 批次采用部分成功语义，每项返回 `imported`、`skipped` 或 `failed`，前端展示汇总。
- 写入目标、项目访问校验、仓库相对路径校验、重解析点防护及 Git 行为沿用已有项目文档规则。

## 验收

1. 多选文本、DOCX、XLSX、PPTX、PDF 后均可预览并引用到聊天。
2. ZIP 中支持项成功、不支持项显示跳过。
3. 不安全路径、嵌套 ZIP、超限条目不会写入磁盘。
4. 单项失败不回滚同批其他成功文档。
5. 注册仓库目标形成 Git 变更，专用区不进入 Git。
