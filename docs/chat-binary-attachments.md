# 聊天 ZIP、RAR 与 DLL 附件

在聊天选择 Codex 本地代理后，通过附件按钮选择 `.zip`、`.rar`、`.dll`；沿用文件附件预览、发送、历史保存及原文件下载流程。每轮最多 4 个文件，单文件最多 20 MB（管理员配置可降低上限）。

## 解析内容

- ZIP/RAR：文件清单、支持的文档正文、文本与常见源码（如 C#、TypeScript、Python、JSON、XML）。DLL 条目也可提取静态元数据。未知格式及嵌套压缩包仅列出名称，不递归展开。
- DLL：PE 架构、节信息；.NET 程序集额外提取程序集名称、版本、依赖、类型和方法名称。支持 .NET 应用程序生成的 DLL。原生 DLL 不提供函数反编译，.NET DLL 不还原方法实现。
- 解析文本通过现有附件上下文交给 AI，标记为不可信证据；不执行压缩包内文件，也不加载执行 DLL。每文件最多 40000 字符，继续使用现有总提取预算与截断提示。

## 边界

使用 SharpCompress 读取 ZIP/RAR，不依赖系统安装 WinRAR。检查文件签名、条目数量、加密、路径及链接；最多 1000 条目、单条目 20 MB、声明展开总大小 100 MB，写出时再次限制实际字节数。条目使用随机临时文件名，解析后清理，不以压缩包路径写入磁盘。

加密、损坏、分卷压缩包不作为支持格式。部分无法解析的条目会显示说明；PDF、旧版 Office 等继续依赖现有文档解析配置。大量文件可能因上下文预算只提取部分内容，可拆包上传。

## 验证

`dotnet test backed.tests/AiAgent.Backend.Tests.csproj --filter FullyQualifiedName~ChatFileAttachmentServiceTests`

覆盖 ZIP、RAR4 存储条目与 .NET DLL 的上传、提取、持久化、重启读取、跨用户拒绝、取消，以及伪造格式、路径穿越、超大条目拒绝。另执行前端 TypeScript 检查。压缩 RAR5/固实包和浏览器完整聊天仍需实际环境验收。
