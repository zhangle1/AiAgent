### 2. 接入 Codex AI 变化解读

- 复用现有 Codex 模型策略和推理等级，由用户显式发起分析；使用独立只读任务上下文，与正在进行的聊天分开。
- 根据当前项目、模块、日期和人员范围准备有限的提交与代码差异证据，生成变化概括、业务名称候选、影响推测和验证建议。
- 返回结构化结果，校验引用是否来自本轮证据；无效输出不发布、不缓存，成功结果按用户、快照和请求参数缓存。
- 右侧 AI 回答可点击查看差异；切换项目、模块、日期或人员后取消旧请求，阻止迟到回答和旧差异覆盖新选择。
- 完成相关 GitHub 项目调研、交互原型和技术方案，明确 Git 事实、结构解析、业务映射及 AI 推测的职责。

### 3. 平台聊天同步与历史会话导入

- 网页聊天回答完成并保存后，将用户与 AI 对话追加到原所属人员的会话 Markdown；重复同步和重复导入去重。
- 知识工作区目录加号改为下拉菜单，保留「添加资源」，增加「导入平台会话」。
- 普通用户只列出、导入本人的会话；管理员可跨人员勾选，导入结果仍归原会话所有者。
- 导入只保存原始对话，不自动解析、编译或调用模型。
- 提交前补充批量校验：单次超过 100 个去重会话时明确提示分批，避免静默截取部分选择。
