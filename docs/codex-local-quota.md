# Codex 本地额度

侧栏原新手引导位置改为仪表盘形额度图标，点击显示订阅类型、各额度窗口的剩余百分比与重置时间；账号位置只显示固定文案“本地来源账号”，不展示邮箱及脱敏片段。取消新手引导自动弹出和工具菜单入口。

账号取自后端实际运行环境的默认 Codex 登录，通过与聊天相同的命令解析逻辑启动独立 app-server，不指定第三方 Profile。它属于后端运行账号，使用同一后端的已登录用户看到同一份额度；不等于网页用户个人统计。不支持 API Key 额度，缺失窗口不补造数据。

`GET /api/v1/chat/codex/quota` 先校验平台登录，再调用服务层。独立只读进程仅执行 initialize、initialized、account/read、account/rateLimits/read，无模型调用、聊天轮次或认证文件读取。响应仅包含状态、订阅、额度窗口和更新时间等白名单字段。服务不提取或缓存邮箱，响应不含 `account_hint`、邮箱域名或脱敏片段，也不返回路径、原始错误、账号 ID 或凭据。前端即使收到旧接口的额外账号字段也不展示。

缓存为单实例进程内共享缓存，通过信号量合并并发。有效结果及未登录／不支持状态缓存 30 分钟；异常缓存 1 分钟，避免反复启动 CLI。缓存过期由下一次查询更新，不设无人使用时仍轮询的后台定时任务。弹窗打开期间按 next_refresh_at 更新，关闭即取消浏览器请求。后端命令变化使缓存失效；外部切换 Codex 登录账号最多延迟 30 分钟显示，重启服务可清空缓存。整体查询限制 25 秒，取消／异常清理独立进程。

官方协议：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。接口 `used_percent` 保持官方 `usedPercent` 的已用含义，前端以 `100 - used_percent` 显示剩余，百分比和进度条使用同一个剩余值，至多保留两位小数。300 分钟显示“5 小时额度”，10080 分钟显示“每周额度”，其他窗口按真实分钟／小时展示，长度缺失时保留主要／次要标签；不推算剩余 Token 或金额。

验证使用隔离临时目录与合成 CLI：并发缓存、过期重查、登录缺失、不支持账号、错误脱敏和取消；浏览器用合成接口验证额度弹窗及移动端。未读取真实账户凭据或调用真实模型。后端目标 net9.0，本机验证使用已有 .NET 10 SDK，测试以 DOTNET_ROLL_FORWARD=Major 在 .NET 10 运行。

2026-11-10 剩余显示回归：合成 80%／69% 已用响应先复现缺少“剩余 20%／31%”的失败断言，修改后验证文字和进度条一致，同时覆盖剩余 0%／100%、小数、不同窗口和缺失次窗口、账号来源标注、未登录、Escape、桌面及 390px 手机布局。TypeScript 和 `git diff --check` 通过；后端读取与 30 分钟缓存机制保持，未查询真实账号或调用模型。
