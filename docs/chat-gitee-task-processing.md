# 聊天页处理码云任务

聊天左侧「新聊天」下方提供「处理码云任务」入口。弹窗复用企业工作项搜索、状态筛选、分页和详情预览，无需切换导入模式。

每行「处理」先调用现有关联接口，将工作项保存至所选 AiAgent 项目，再准备聊天交接（任务正文及图片），进入新聊天自动发送。默认使用当前会话／路由项目，没有当前项目时使用首个可用项目，也可在弹窗更改。没有项目时不可处理。

准备阶段锁定处理按钮和项目选择，失败保留弹窗供重试。自动发送只消费当前浏览器点击处理产生的单次标记，等待聊天配置及附件准备完成，避免重复发送；普通任务面板及模板预填保持手动发送。模型配置不支持附件时沿用聊天校验，保留草稿并提示原因。

AiAgent 项目选择器展开后支持按项目名称实时过滤（忽略大小写及首尾空格），长列表独立滚动，完整展示项目名及当前选中标记。过滤不改变已选项目；点击结果才切换目标，Escape 收起项目列表而不关闭任务弹窗。无匹配及无可用项目时显示明确提示。

验证：TypeScript 检查、模拟接口浏览器测试（搜索、直接处理、重复点击、失败重试、原有关联模式），聊天回归测试。不使用真实码云账号或模型调用。
