# 聊天项目 ZIP 下载

聊天中的本机 ZIP 路径、项目相对 ZIP 路径和当前项目下载 API 链接显示为下载卡片。点击通过同源 API 获取 Blob 后保存，失败在卡片内显示，不导航到本机路径或错误页面。外部 URL 保持普通链接。

资料列表默认扫描项目根目录及关联代码库，按真实文件路径去重，关联代码库优先。项目根目录使用内部标识 `__project_root__`，不要求注册代码库。根目录文档沿用预览和下载白名单；ZIP 允许位于项目根目录、download 或其他受控子目录，只下载不解析。

下载沿用项目访问权限，服务端确定根目录，拒绝目录穿越、排除目录和 ZIP 路径中的链接。绝对路径必须经当前项目的服务端引用解析，不能按同名文件回退。

新增打包仍默认写入被 Git 忽略的 `artifacts/aiagent-packages/`，历史 ZIP 不要求移动。

验证使用临时项目及 SQLite：未注册代码库的项目根目录下载、关联代码库去重、项目隔离、路径穿越；前端验证路径识别、当前项目 API、原始字节和文件名、失败反馈。
