# 首轮：项目企业模型与 MES 工作台

入口：聊天右上角「＋ → 本体模型」。独立组件按当前项目和用户保存多份企业模型。切换项目或会话关闭旧面板并清除未保存密码，迟到响应不能覆盖新项目。

模型包含名称、数据库类型、主机、端口、数据库名、账号、密码与流程图。密码通过服务端 Data Protection 加密存储，仅返回 has_password；空密码保留原值。密码不进入流程、上下文、日志或浏览器持久化。版本冲突返回 409。

节点插件目录定义 source、transform、output，支持增删节点、编辑标签、分支连线与删除边。页面和 LLM 共用图 API，校验类型、唯一 ID、引用、循环及数量。首轮为内置插件注册表，不加载任意代码。流程只描述编排，不执行 SQL 或数据转换，不声称数据库已经连通。

服务端按模型生成脱敏上下文，预览后显式填入聊天草稿，不自动发送。上下文含模型引用、数据库类型、节点及连线，不含主机、账号、密码。LLM 通过宿主已有授权 HTTP 能力读取插件目录、图与上下文，提交图后可在面板刷新查看；不能通过图 API 改写连接或读取密码。

原生 Codex CLI、工具、权限、会话与调度保持原状。未打开入口不请求本体 API。真实驱动验证、ETL 执行器、元数据探测及企业共享授权后续实现；首轮配置按用户隔离。

验收：项目与用户隔离、凭据不回显、图校验、版本冲突、上下文脱敏、迟到响应隔离，以及前后端编译。只用合成数据验证。
