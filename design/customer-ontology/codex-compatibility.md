## Codex CLI 兼容边界（实施硬性要求）

现有 Codex CLI 已有良好体验，本工作台仅提供可选的业务上下文和工具能力增强。接入以保持现有能力与体验为前提，不替换 Codex CLI 的原生执行流程，不要求所有任务先建本体、配置连接或经过节点工具链。

- **默认沿用原流程**：未选择本地能力时，不注入额外 Prompt、不查询连接、不加载本体，也不增加验证等待或必填步骤；原有会话和普通编码任务继续运行。
- **原生能力继续可用**：保留现有文件读写、代码检索、命令执行、测试、Git、会话继续、流式输出、停止与恢复，以及已有工具、MCP、Skills 和用户配置的行为。新增适配器不得覆盖已有配置或收窄原生工具清单；具体回归项以当前已支持能力为基线。
- **显式附加、可查看和移除**：用户选择连接或模型后才生成上下文，预览后填入草稿或导出，发送前可修改、移除。内容作为有来源的任务补充材料，不覆盖用户原文、系统指令或项目指令，也不全量加载公司模型挤占上下文。
- **执行仍由 Codex 负责**：工作台提供连接引用、验证证据、业务语义和可调用工具；Codex 自行规划并使用现有能力。节点链是可选预制流程，不作为所有工具调用的必经入口，不另建循环接管 Codex 的原生执行与续跑。
- **故障限于新增能力**：执行器离线、连接失效或本体服务不可用时，只将所选扩展标记为不可用，不阻断无关编码任务。用户可移除扩展继续；不得静默将失败任务改为成功，也不得自动改用其他环境或绕过该连接的权限。
- **权限分别生效**：本工作台的只读、范围白名单、凭据引用与 prod 限制约束通过工作台管理的连接和工具，不据此禁用原有 CLI 命令或改写全局权限。原生操作继续遵守原有权限与审批配置；工作台授权不扩大原生权限。
- **可关闭、可回退**：新增入口、上下文注入及适配器可独立关闭；关闭后恢复原有路径，保留既有会话、配置和工具。

兼容验收需对照接入前基线：未启用时完成原有编码、测试、工具调用、会话继续与取消流程；启用时可同时使用原生工具和新增能力；移除上下文后后续请求不再附加；扩展超时或失败不影响无关任务；关闭功能后仍能使用原有会话。未选择扩展时不得新增扩展网络请求或模型调用。以上为待实施的验收要求，不表示本轮已完成 CLI 集成或回归。
