Capability model

Skill 不等于 Prompt

Workflow依赖、分支、并行、重试和人工等待；消费 Skill 的 typed input/output。
Skill标准作业包：触发描述、步骤、输入输出、权限、风险、引用、脚本和测试。
Tool最小结构化动作；由服务端执行并实施权限、路径和风险校验。
Prompt一次任务的文字脚手架；可以被 Skill 引用，但不能获得执行权限。

P0 · 只读

复用：Git · Code Search · Knowledge

测试失败分诊

聚类失败，定位首因，产生最小复现与修复候选。

交付验收包

ADR 生成与回链

P1

从已确认讨论生成 ADR，并保留会话、代码和证据回链。

证据冲突侦测

发现代码、文档、知识库和记忆对同一事实的冲突。

变更集沙盒

返工雷达

Domain opportunities

八个领域建设点

01

Run Ledger

  • 追加式事件与单调 sequence
  • 断线补拉、恢复、取消、预算
  • 聊天/画布/任务共享事实源
02

Approval Inbox

  • 批准、编辑、拒绝、转交
  • 动作目标、副作用、证据、回滚
  • Web 与钉钉双投影
03

Skill Registry

  • 版本、签名、授权、兼容性
  • 触发/权限/结果/成本评测
  • 灰度、弃用与回滚
04

Artifact + Change Set

  • 有类型的文件、diff、报告、截图
  • 基线哈希、验证、处置状态
  • 隔离工作树支持并行会话
05

Project Knowledge Graph

  • 任务—会话—Run—提交—知识回链
  • 先用关联表与查询投影
  • 支持证据透镜与代码库考古
06

Evaluation & Replay

  • 脱敏 Run 生成回归案例
  • 副作用工具 mock/dry-run
  • 版本对比与失败归因
07

Context Compiler

  • 统一编译规则、记忆、任务、RAG、diff
  • 来源、预算、版本可解释
  • 冲突和过期检测
08

Project Pulse

  • 首轮通过率、返工和审批等待
  • Skill 成功率与知识命中率
  • 每个已验收交付的真实成本
Governance by action

按动作分级，而非全开或全关

R0 · 自动

搜索、读取、RAG、diff 等无副作用动作。

R1 · 可配置

工作区补丁、新建草稿；先展示计划，项目可允许自动。

R2 · 必须审批

Git push、外发消息、修改共享知识。

R3 · 双确认/禁用

删除、发布、生产命令、权限变更。
