Skill

可复用工作方法，不授予权限。

  • SKILL.md + scripts/references/assets
  • 沿用 Codex 发现和结构化 skill input
  • 平台增加版本固定、签名、风险扫描

Plugin

能力的安装与分发单元，不是常驻 Agent。

  • 组合 Skill、MCP、App、Hook
  • Installed ≠ Enabled ≠ Granted
  • 并行版本、升级审核、可回滚

Runtime Adapter

Native 为默认，外部 Runtime 可替换。

  • Codex app-server v2 首个 Adapter
  • 统一能力探测、事件与审批映射
  • 外部协议不泄露到业务 API

协作硬边界

  • 父任务给出 goal、scope、预算、deadline 与 output schema。
  • spawn/message/wait/interrupt/collect 是平台原语。
  • 一个 writer 或隔离 worktree，避免共享目录盲目并写。
  • Agent 不能自行永久扩权、安装插件或创建无限自动化。
  • 结果先落为 Artifact，再由父 Agent 收敛。
