# 会话信息流与 Skill 契约原型

本目录扩展现有 Agent Work Canvas，聚焦三个能力：

- 会话之间通过有方向的连线传递“上下文包”，而非隐式共享完整聊天历史；
- 每个会话节点可绑定 Skill、职责、输入/输出约定和行为约束；
- 在画布上直接观察上下游状态、传递内容、阻塞原因和运行记录。

文件说明：

- `session-flow-prototype.html`：可直接用浏览器打开的交互原型；点击节点、连线、检查器页签和“模拟运行”可查看主要状态。
- `session-flow-design.md`：产品模型、交互规则、数据结构、运行语义、安全边界和分期建议。

该目录仅包含设计稿，不修改生产接口和现有画布实现。
