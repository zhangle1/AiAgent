# 独立会话投递原型

本目录用于验证无限画布中的“独立会话 + 按需投递”体验。

- `session-flow-prototype.html`：可直接用浏览器打开的交互原型。
- `session-flow-design.md`：产品模型、交互规则、数据边界与分期建议。

这不是 Agent 工作流编排器。画布中的每张卡片都是真实、完整、可独立运行的会话；人工连线只建立可投递关系。发送方完成工作后选择需要交付的内容，接收方检查后再决定是否带入会话或触发新一轮执行。

原型中的主要可操作项：

1. 点击任意会话卡片，查看该会话自身的 Skill、职责与约束；
2. 点击人工连线，查看投递关系和最近记录；
3. 点击“选择内容并投递”，打开投递编辑器；
4. 切换到“接口实现”会话，对待检查投递执行接收、编辑后接收或忽略；
5. 点击“带入并开始新一轮”，观察它只启动目标会话的新一轮，不联动其他会话。

本目录仅包含设计稿，不修改生产接口和现有画布实现。
