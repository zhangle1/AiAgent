# 项目工作空间实施 Tickets

前置：用户确认 `docs/project-workspace-prototype-2026-09-17.html` 的最终布局。规格以 `docs/project-workspace-spec-2026-09-17.md` 为准。

## P0：领域与存储

- [ ] PW-01 定义 ProjectAsset、Artifact、ArtifactVersion、ProjectContextSource 数据契约；新增字段保持可空并补迁移验证。
- [ ] PW-02 建立项目隔离的受控文件目录与路径校验服务，覆盖上传、下载、预览、移动、软删除和额度。
- [ ] PW-03 复用现有文档解析/预览能力，为项目资料增加逐文件导入结果和异步知识化状态。
- [ ] PW-04 建立 AI 产物版本服务，支持创建、预览、下载、转项目资料和显式导入代码仓。

完成标准：后端测试证明跨项目访问被拒绝、路径逃逸被拒绝、资料不会写入 Git 仓。

## P0：项目上下文

- [ ] PW-05 扩展聊天请求契约，传递项目默认来源与本轮覆盖项；服务端按权限重新解析，不能信任前端资源 ID。
- [ ] PW-06 将项目知识设为默认检索范围，并返回实际采用的来源摘要与跳过原因。
- [ ] PW-07 支持把聊天临时附件显式转存到项目资料，保留来源与会话引用。

完成标准：集成测试覆盖默认范围、逐项关闭、无权限来源和附件转存。

## P1：统一项目页面

- [ ] PW-08 新增项目详情壳与固定项目选择，接入概览、对话、资料、产物、仓库、知识、设置导航。
- [ ] PW-09 实现项目资料页：目录、搜索、筛选、上传、预览、下载、移动、删除和知识化状态。
- [ ] PW-10 实现 AI 产物页与聊天产物卡片：版本、预览、下载、转存和导入代码仓。
- [ ] PW-11 整合现有多仓库页面，保留 Git 状态、diff、测试和提交审批流程。
- [ ] PW-12 在聊天输入区实现“本轮上下文”条，显示项目知识、仓库、资料和临时附件。

完成标准：桌面端和窄屏均可完成“上传资料 → 聊天引用 → 生成 HTML → 预览/下载”的闭环。

## P1：Harness 与运行状态

- [ ] PW-13 分离空间能力与执行能力状态；未连接时解释限制，连接后显示授权工作目录和执行模式。
- [ ] PW-14 为代码执行结果增加变更文件、测试结果、diff 和待审批提交入口。

完成标准：断开 Harness 不影响服务端资料、知识和产物；本地路径永不由浏览器直接提交给服务端执行。
