# Knowledge Base Learning Lab

本上下文描述知识如何从外部材料变为可检索、可引用和可演进的证据。它刻意区分业务事实、处理产物和用户记忆。

## Language

**资源**：
知识库接收的外部材料及其来源身份，例如文件、网页或代码仓库；资源不是解析后的正文。
_Avoid_: 文档内容、分块

**解析产物**：
从资源生成的标准化、可复现中间表示，通常由正文 Markdown 与来源清单组成。
_Avoid_: 原文件、索引

**上下文节点**：
知识层级中的一个可寻址语义对象，可以是目录、文档、章节或内容块。
_Avoid_: 任意 JSON、搜索结果

**L0 摘要**：
用于快速判断一个上下文节点是否值得继续探索的一句话摘要。
_Avoid_: 全文摘要

**L1 概览**：
描述一个上下文节点的结构、主题和适用问题的中等长度概览。
_Avoid_: 内容块

**L2 内容**：
保留原始事实和来源定位的详细内容，是生成答案时引用的主要证据。
_Avoid_: 摘要

**索引版本**：
由固定的资源版本、解析配置、切分配置和检索模型共同产生的一组不可变检索产物。
_Avoid_: 当前目录、缓存

**候选召回**：
从允许访问的范围中找出的、尚未最终排序和裁剪的上下文节点集合。
_Avoid_: 最终答案、引用

**检索证据**：
最终提供给回答生成器和用户的可定位内容，必须指向资源、节点和索引版本。
_Avoid_: 模型推测、无来源摘要

**记忆观察**：
从会话中捕获、等待提炼的受控事实片段，不会直接成为长期记忆。
_Avoid_: 长期记忆

**长期记忆**：
经过作用域校验和审核、可跨会话复用的用户或项目知识。
_Avoid_: 聊天历史、知识库文档
